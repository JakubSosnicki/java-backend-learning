# Java Backend Learning Journey

Welcome to my **Java Backend Learning** repository!

This repository documents my journey toward becoming a **Java Backend Developer**. It contains weekly programming exercises, practical projects, and coding challenges designed to strengthen my understanding of Java and backend development.

## Goals

The main goals of this repository are to:

- Build a strong foundation in Core Java.
- Develop problem-solving and algorithmic thinking skills.
- Apply Object-Oriented Programming (OOP) principles.
- Practice writing clean, readable, and maintainable code.
- Learn how to use Git and GitHub for version control.
- Improve my knowledge of backend development through hands-on projects.
- Track my progress and continuously improve my programming skills.

## Technologies & Tools

Technologies and tools used throughout this learning journey:

- **Java** - Main programming language
- **IntelliJ IDEA** - Integrated Development Environment
- **Git & GitHub** - Version control and repository management
- **JUnit** - Unit testing
- **Maven / Gradle** - Build automation (as needed)

Additional technologies will be introduced as my learning progresses.

## Topics Covered

## Development Workflow

I use Git to track changes and experiment with different implementations.

My typical workflow includes:

1. Creating a new exercise or feature branch.
2. Implementing the required functionality.
3. Committing meaningful changes.
4. Testing and refactoring the code.
5. Merging completed work into the `main` branch.
6. Pushing changes to GitHub.

This approach helps me practice version control and maintain a clear development history.
